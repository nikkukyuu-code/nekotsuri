# 猫ハウスつり（β版）

猫ハウスで人が猫を釣るブラウザゲーム。スマホ・PC対応。

- 説明ページ: https://nikkukyuu-code.github.io/nekotsuri/
- 遊ぶ: https://nikkukyuu-code.github.io/nekotsuri/game/

公開時は `python3 tools/stamp.py` でバージョン（公開日時 Asia/Tokyo）とキャッシュバスター `?v=YYYYMMDDHHmmss` を更新する。

保存キー（変更禁止）: `nekotsuri-save-v1`, `nekotsuri-save-v1-bak`, `nekotsuri-pref-v1`。
全ゲーム共通の引き継ぎ: https://nikkukyuu-code.github.io/transfer/ （nikkukyuu-code.github.io リポジトリの transfer/transfer.js に登録済み）。
